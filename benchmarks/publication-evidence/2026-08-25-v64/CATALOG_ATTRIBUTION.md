# Catalog attribution

The order-10 population is Brendan McKay's `graph10.g6.gz` data file.

Source:
https://users.cecs.anu.edu.au/~bdm/data/graph10.g6.gz

Collection:
https://users.cecs.anu.edu.au/~bdm/data/

The collection page states that, except where data was compiled by someone else,
Brendan McKay releases the data files in the collection under the Creative Commons
Attribution 4.0 International license (CC BY 4.0).

This publication bundle does not embed the raw order-10 catalog. It records exact
compressed and decompressed hashes binding the external source.
